# Project sources

## Universal Embedded Workbench

https://github.com/SensorsIot/Universal-Embedded-Workbench

Used for the ESP workbench / RFC2217 portal model.

## Bruxy Home Assistant development

https://github.com/bruxy70/ha-development

Reference for Home Assistant / ESPHome development patterns. The
`esphome-lvgl` and `svg-rendering` skills are especially relevant for CrowPanel
UI work: LVGL structure, display/touch pitfalls, Home Assistant action gotchas,
and pixel-accurate SVG mockups before implementing a UI on-device.

## Elecrow CrowPanel wiki

https://www.elecrow.com/wiki/CrowPanel_1.28inch-HMI_ESP32_Rotary_Display.html

Primary source for CrowPanel hardware details.

## Elecrow CrowPanel ESPHome course

https://www.elecrow.com/wiki/CrowPanel_HMI_ESP32_Rotary_Display_ESPHome_course.html

Primary source for Elecrow's own ESPHome examples for the 1.28 inch rotary
CrowPanel. Use this with the GitHub repo's `example/esphome/` lesson YAMLs when
resolving display, backlight, touch, rotary, and LVGL behavior.

buying/support links.

## Elecrow CrowPanel GitHub repo

https://github.com/Elecrow-RD/CrowPanel-1.28inch-HMI-ESP32-Rotary-Display-240-240-IPS-Round-Touch-Knob-Screen
